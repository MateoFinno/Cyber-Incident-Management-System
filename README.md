## Overview

Cyber Incident Management System is an ASP.NET Core MVC web application designed to manage cybersecurity incidents, digital assets, user accounts and access permissions within an organization.

The system allows administrators to manage users, accounts and assets, while tracking cybersecurity incidents such as Phishing and Ransomware attacks through a centralized platform.

The application implements role-based access control, incident severity assessment and Object-Oriented Programming principles including inheritance, polymorphism and encapsulation.
